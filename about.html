About Fun Finds Geocaching

Fun Finds Geocaching is my final project for the Fall 2025 Website Development course at Ivy Tech. The site demonstrates class concepts through a custom geocaching experience. Geocaches represent real-world locations for demonstration only; there are no physical caches. When location permissions are enabled, the map shows your location (green) and geocaches (blue). Any location or email data is used solely to support map and login functionality and is not stored or shared outside Firebase for authentication purposes.


Learn more about Firebase at firebase.google.com

Check out the Leaflet.js map library at leaflet.js

Learn more about geocaching on geocaching.com
