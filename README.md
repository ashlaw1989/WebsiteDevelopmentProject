# Fun Finds Geocaching

**Live site:** https://ashlaw1989.github.io/WebsiteDevelopmentProject/

Fun Finds Geocaching is a multi-page website created as my final project for Website Development. The site allows users to explore geocache locations and, when logged in, view an interactive map to get started. (Real locations, no actual geocaches)

## About

This site was built using HTML, CSS, and JavaScript with a focus on responsive design, accessibility, and DOM manipulation. All pages share a consistent layout, navigation, and visual style.

I also went beyond the course requirements by learning and implementing Firebase Authentication and Leaflet.js through tutorials to support user login and interactive maps.

## Pages

- Home
- Geocaches
- About
- Login

## Features

- Responsive, mobile friendly layout
- Account creation, login, and logout
- JavaScript form handling validation
- Interactive map available only when logged in
- Modal popups for account create, start geocaching, and logout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Leaflet.js
- GitHub Pages

## Data & Privacy Notice

Any information collected (such as email or location data) is used only for demonstration purposes. User authentication is handled through Firebase, and location access is used solely to enable map-related features. No data is stored, shared, or used outside the scope of this project.
